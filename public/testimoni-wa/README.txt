Tangkapan layar percakapan WhatsApp untuk bagian testimoni.

Ukuran:  1080 x 2280 piksel (rasio 9:19)
Format:  .jpg, .jpeg, .png, atau .webp
Berkas:  usahakan di bawah 300 KB per gambar
Nama:    bebas, tapi urutannya mengikuti nama berkas.
         Pakai wa-1.jpg, wa-2.jpg, wa-3.jpg supaya rapi.

Taruh berkasnya di folder ini — selesai. Tidak ada kode yang perlu diubah:
folder ini dipindai sendiri, jadi berapa pun jumlah berkasnya akan tampil.

Pemindaian terjadi saat build. Setelah menambah atau mengganti berkas,
jalankan ulang `npm run dev` atau `npm run build` supaya terbaca.

Gambar dipasang object-cover object-top, jadi kalau lebih tinggi dari rasio
9:19 bagian bawah terpotong. Taruh bagian percakapan terpenting di atas.

Berkas selain gambar (seperti README.txt ini) diabaikan.

Pakai tangkapan layar yang betul-betul ada. Percakapan yang dikarang adalah
testimoni palsu, dan satu saja yang ketahuan cukup untuk meruntuhkan
kepercayaan pada seluruh testimoni di halaman ini.
