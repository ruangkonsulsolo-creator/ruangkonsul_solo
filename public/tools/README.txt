Logo perangkat lunak untuk bagian "Perangkat" di beranda.

Cara memakai logo resmi:
1. Unduh dari situs resmi masing-masing (cari "press kit" / "brand assets"),
   bukan dari hasil pencarian gambar.
2. Simpan di folder ini dengan nama sesuai slug:
   spss.png  smartpls.png  amos.png  stata.png  eviews.png  r.png
   nvivo.png  atlasti.png  mendeley.png  zotero.png  vosviewer.png  python.png
3. Format PNG latar transparan, sisi terpanjang 160 px.
4. Buka components/landing/KartuTool.tsx, tambahkan `adaLogo: true`
   pada entri yang berkasnya sudah ada.

Selama belum ada, kartu memakai monogram berwarna.
